📊 Análisis de Ventas y Rentabilidad con Power BI

📌 Objetivo
Analizar el desempeño de ventas de una empresa para identificar patrones de rentabilidad, comportamiento por métodos de pago y variaciones regionales que permitan mejorar la toma de decisiones comerciales.

📂 Dataset
-  Datos de ventas simulados
-  Variables principales:
*Ventas
*Costos
*Rentabilidad
*Método de pago
*Ubicación geográfica
*Tamaño de producto

🛠️ Herramientas utilizadas
-  Power BI
-  Modelado de datos
-  Visualización de datos


🔍 Insights principales
📈 Las ventas muestran una tendencia creciente hacia fin de año, con un pico en diciembre
💳 Los métodos de pago con tarjeta presentan mayor volumen de ventas, pero no necesariamente mayor rentabilidad
📍 Existen diferencias significativas en ventas entre provincias, destacándose ciertas zonas como principales generadoras de ingresos
📦 Los productos de mayor tamaño concentran mayores costos, afectando la rentabilidad
🚀 Valor del análisis

Este dashboard permite:
-  Monitorear el rendimiento comercial en tiempo real
-  Identificar oportunidades de mejora en rentabilidad
-  Analizar el impacto de los métodos de pago
-  Detectar regiones clave para el negocio
